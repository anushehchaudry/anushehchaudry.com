# anushehchaudry.com

Personal site of Anusheh Chaudry, built with [Astro](https://astro.build) and published with GitHub Pages.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # static site in dist/
```

Pushing to `main` deploys automatically (see `.github/workflows/deploy.yml`).
Blog posts go in `src/content/writing/` (copy `_template.md`).
